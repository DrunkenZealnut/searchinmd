# 의미 출현 등급 결합 설계

> Version: 1.0.0 | Date: 2026-09-09 | Status: Approved
> Level: Starter | Plan: `docs/01-plan/features/semantic-occurrence-grades.plan.md`

## 1. 개요

의미 재검산의 출현 레코드에 해당 페이지의 통일 등급을 결합한다. 기존에 판정된 페이지는 그 등급을 보존하고, 의미 확장으로 처음 검출된 페이지만 기존 기준선 함수로 판정한다. 결과 Excel과 정적 대시보드는 같은 결합 결과만 사용한다.

## 2. 데이터 흐름

```text
기존 NCS 등급 Excel ─────────────┐
기존 교과서 등급 Excel ─→ 통일 등급 변환 ─┤
                                             ├→ 문서·페이지 등급 인덱스
Markdown 페이지 본문 ───────────────┘   (인덱스에 없는 페이지만 신규 판정)
                                             ↓
semantic MatchRecord + GradeAssignment
                    ↓                   ↓
        재검산 XLSX/보고서      대시보드 데이터/화면
```

NCS 원본 두 파일(`20260402.xlsx`, `20260402_재판정_20260414.xlsx`)은 데이터 행의 다중집합과 페이지 등급이 동일함을 확인했다. 사용자가 지정한 `20260402_재판정_20260414.xlsx`를 기존 NCS 판정의 직접 출처로 사용한다. 교과서는 `ncs_keywords_in_markdown_results_교과서_results_20260415.xlsx`를 읽고 원본 등급을 통일 등급으로 변환한다.

## 3. 데이터 구조

각 포함 출현 레코드에 다음 속성을 추가한다.

| 필드 | 값 | 설명 |
|---|---|---|
| `grade` | `1`, `2`, `3`, `None` | 통일 등급. 페이지 미확정은 `None` |
| `grade_label` | 미흡·없음 / 형식적 언급 / 구체적 대책 / 등급 미확정 | 표시명 |
| `grade_reason` | 문자열 | 기존 또는 신규 판정 사유 |
| `grade_source` | `existing` / `new` / `unpaged` | 등급 계보 |

페이지 인덱스 키는 `(corpus, canonical_document, page)`다. 파일명은 NFC 정규화, 경로·확장자·타임스탬프 접두어 제거 후 비교하며, NCS 능력단위 코드(`LM`+10자리)는 보조 키로만 사용한다.
단, 신규 페이지의 본문과 계산 결과는 `(corpus, relative_path, page)`로 저장해 같은 LM 코드를 가진 복수 Markdown의 본문이 섞이지 않게 한다.
기존 등급은 정규화된 전체 문서 키가 현재 페이지 문서 하나에만 대응할 때 승계한다. 전체 문서명으로 일치하지 않을 때만 LM 코드를 보조 키로 쓰며, 기존·현재 중 어느 쪽에서든 모호하면 승계하지 않고 신규 페이지로 판정한다.

## 4. 등급 결합 규칙

1. 페이지가 없으면 `grade=None`, `grade_source=unpaged`로 둔다.
2. 페이지가 기존 등급 인덱스에 있으면 기존 등급·사유를 그대로 상속한다.
3. 인덱스에 없는 페이지는 같은 `PageBlock` 전체 본문을 `regrade.grade_page(word_boundary=False, normalize=False)`로 판정한다.
4. 등급별 출현건수는 포함 레코드 수를 등급별로 센다. 페이지 수로 환산하지 않는다.
5. 등급1+2+3 합은 `grade is not None`인 출현 수와 반드시 일치해야 한다.
6. 페이지 미확정 출현은 의미 출현 총계에는 포함하지만 등급 비율 분모에서는 제외한다.

## 5. Excel 출력

- `요약`: 말뭉치·키워드별 등급1~3 출현건수와 미확정 건수 추가
- `NCS_파일별`, `교과서_파일별`: 파일·키워드별 등급1~3 출현건수와 미확정 건수 추가
- `NCS_매칭상세`, `교과서_매칭상세`: 등급, 등급명, 등급사유, 등급 출처 추가
- `README`: 등급 단위, 기존/신규 판정, 페이지 미확정 처리 설명 추가
- 원본 두 등급 Excel은 읽기 전용으로 유지

## 6. 대시보드 구성

두 페이지는 다음 순서를 공유한다.

1. 분석 대상과 출현건수 요약
2. 등급1·2·3 KPI와 등급 미확정
3. 전체 등급 분포와 상위 키워드별 등급 분포
4. 키워드별 상세 표
5. NCS 영역별 또는 교과서별 출현 현황
6. 문제점과 시사점
7. NCS와 교과서 비교
8. 개선 권고안

모든 비율·차트·표의 주 단위는 의미 출현건수다. 페이지 수는 원문 위치와 미확정 상태 설명에만 사용한다.

## 7. 구현 대상

- `semantic_keyword_recount.py`: 등급 인덱스, 신규 페이지 판정, 결합 집계, XLSX 출력
- `test_semantic_keyword_recount.py`: 등급 결합과 출력 테스트
- `docs/semantic_recount_data.js`: 등급별 출현 집계 데이터
- `docs/index.html`, `docs/textbook.html`: 공통 분석 흐름과 출현건수 표시
- `docs/semantic_grade_dashboard.js`: NCS·교과서 공통 등급 렌더러
- `outputs/test-dashboard-data.js`: 실제 렌더·수치·흐름 회귀 검증

## 8. 테스트 계획

- 기존 페이지 등급 상속과 사유 보존
- 신규 페이지에서 기준선 등급 판정
- 페이지 미확정 레코드 분리
- 키워드·파일·말뭉치별 등급합 정합성
- XLSX 헤더와 상세행 등급 계보 확인
- 두 대시보드의 동일 섹션 순서, 등급명, 출현건수 분모 확인
- 전체 Python·Node 테스트와 XLSX ZIP 무결성 검사

## 9. 구현 순서

1. 실패 테스트 작성 및 실패 원인 확인
2. 등급 결합 데이터 모델과 로더 구현
3. 집계와 Excel 출력 구현
4. 실제 Excel 재생성 및 독립 수치 검증
5. 대시보드 데이터와 두 화면 갱신
6. 전체 회귀 테스트와 PDCA 차이 분석

## 10. 학습 포인트

- 출현 레코드와 페이지 등급은 서로 다른 단위이므로 명시적인 결합 키가 필요하다.
- 기존 판정과 신규 판정의 출처를 남겨야 결과를 감사할 수 있다.
- 분모가 출현건수라면 페이지 미확정 여부와 관계없이 총 출현은 유지하되, 등급 분포에는 확정값만 사용해야 한다.
