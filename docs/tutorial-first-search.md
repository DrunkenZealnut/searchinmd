# 튜토리얼: 첫 검색 돌려보기

저장소에 들어 있는 샘플 문서 2개를 키워드 2개로 검색하고, 결과를 Excel로 내보냅니다. 끝나면 이 도구가 무엇을 읽고 무엇을 뱉는지 손으로 겪어본 상태가 됩니다.

10분이면 됩니다. 준비할 자료는 없습니다 — 샘플이 저장소에 같이 있습니다.

## 필요한 것

- **Chrome 또는 Edge.** 폴더 선택에 File System Access API(`showDirectoryPicker`)를 씁니다. Safari·Firefox는 이 API가 없어 2단계에서 막힙니다.
- **Python 3.** 표준 라이브러리만 씁니다. 설치할 패키지 없습니다.
- 저장소를 클론한 상태.

```bash
git clone https://github.com/DrunkenZealnut/searchinmd.git
cd searchinmd
```

## 1단계: 앱 띄우기

```bash
python3 outputs/server.py
```

```text
🚀 서버 시작: http://localhost:3008/search_in_md
종료하려면 Ctrl+C를 누르세요
```

3008 포트가 이미 쓰이고 있으면 서버가 알아서 다음 빈 포트를 잡습니다. 출력에 찍힌 주소를 그대로 Chrome에 붙여넣으세요.

원하는 포트를 직접 줄 수도 있습니다:

```bash
python3 outputs/server.py 9000
```

브라우저에 **1 Excel 파일 선택 / 2 마크다운 파일이 있는 폴더 선택** 순서로 된 화면이 뜨면 성공입니다. 이 터미널은 그대로 두고 새 탭에서 다음 단계를 진행하세요.

## 2단계: 키워드 워크북 만들기

여기가 이 도구의 유일한 낯선 부분입니다. **Excel 워크북의 시트 이름이 곧 검색 키워드입니다.** 키워드 목록을 셀에 적는 게 아니라, 키워드 하나당 시트 하나를 만듭니다.

각 시트의 **1행**은 결과가 들어갈 열 구성이 됩니다. 앱은 헤더 이름을 보고 어느 열에 무엇을 넣을지 정합니다.

| 넣고 싶은 것 | 1행에 쓸 수 있는 이름 (하나만 고르면 됩니다) |
|---|---|
| 순번 | `번호` `number` `no` `no.` `#` |
| 파일 이름 | `파일명` `파일` `문서명` `문서` `filename` `file` |
| 검색된 내용 | `내용` `검색결과` `결과` `content` `contents` · 또는 **키워드 자신** |
| 위치(쪽/줄) | `위치` `페이지` `줄` `줄번호` `page` `line` `location` |
| 페이지 전체 글 | `전체내용` `페이지전체내용` `fullpage` `full page` `page content` |

여기 없는 이름을 쓰면 그 열은 그냥 비워 둡니다. 원본 서식을 지켜야 하는 기존 양식에 결과만 얹으려고 이렇게 만들어져 있습니다.

**손으로 만들기** (Excel · Numbers · LibreOffice · Google Sheets 아무거나):

1. 새 워크북을 만듭니다.
2. 시트 두 개를 만들고 이름을 `AI` 와 `Python` 으로 바꿉니다.
3. 두 시트 모두 1행에 `번호` `파일명` `내용` `위치` `페이지전체내용` 을 차례로 적습니다.
4. `keywords.xlsx` 로 저장합니다.

**명령으로 만들기** (`pip install openpyxl` 이 되어 있다면):

```bash
python3 - <<'PY'
from openpyxl import Workbook
wb = Workbook(); wb.remove(wb.active)
for kw in ("AI", "Python"):
    ws = wb.create_sheet(kw)
    ws.append(["번호", "파일명", "내용", "위치", "페이지전체내용"])
wb.save("keywords.xlsx")
PY
```

이제 앱에서 **📊 Excel 파일 선택** 을 누르고 방금 만든 `keywords.xlsx` 를 고릅니다. 화면에 키워드 `AI` 와 `Python` 두 개가 뜹니다. 뜨지 않으면 시트 이름을 다시 확인하세요 — 셀 내용이 아니라 **시트 탭 이름**입니다.

## 3단계: 폴더 고르고 검색

**📁 폴더 선택** 을 누르고 저장소 안의 `outputs/test-samples` 를 고릅니다. Chrome이 폴더 접근 권한을 물으면 허용하세요.

```text
outputs/test-samples/
├── sample1.md
└── subfolder/
    └── sample2.md
```

**발견된 마크다운 파일: 2개** 가 뜨면 맞습니다. 2가 아니라 1이라면 한 단계 위 폴더를 골랐거나 `test-samples` 안쪽을 골랐다는 뜻입니다 — 하위 폴더까지 재귀적으로 훑기 때문에 `subfolder/sample2.md` 도 잡혀야 합니다.

**🔍 검색 시작** 버튼은 **키워드와 파일이 둘 다 준비돼야** 켜집니다. 순서는 상관없습니다. 눌러도 반응이 없으면 둘 중 하나가 비어 있는 것입니다.

검색 옵션은 기본값 그대로 두세요:

- ☐ 대소문자 구분 — 꺼두면 `AI` 가 `ai` 도 잡습니다
- ☑ 문장 검색 · ☑ 표 검색 · ☑ 이미지 검색
- ☐ LLM 하이브리드 검색 — **끈 채로 둡니다.** 로컬 LM Studio 서버가 따로 필요하고, 이 튜토리얼은 쓰지 않습니다

**🔍 검색 시작** 을 누르면 결과가 키워드별 탭으로 나옵니다.

## 지금 화면에 보이는 것

키워드 탭(`AI` / `Python`)을 오가며 확인해 보세요. 표의 **유형** 열이 세 가지로 나뉩니다.

- **문장** — `Python은 AI 개발에 가장 많이 사용되는 언어입니다.` 같은 본문 문장
- **표** — `| Python | AI 개발 언어 | 3.11 |` 처럼 마크다운 표의 행. 구조를 유지한 채 잡힙니다
- **이미지** — `![시스템 구조도](images/architecture.png)` 와 그 앞뒤 문맥

`Python` 탭에는 `sample1.md` 와 `subfolder/sample2.md` 가 **둘 다** 나옵니다. 하위 폴더까지 훑는다는 뜻입니다.

**위치** 열에는 `L` 이 붙은 줄 번호가 보입니다(`L12` 같은). 원본 PDF 쪽수로 바꾸려면 `_meta.json` 이나 페이지 마커가 필요한데, 이 샘플에는 없어서 줄 번호로 떨어집니다. 쪽수를 붙이는 방법은 [페이지 마커 주입 how-to](howto-page-markers.md)에 있습니다.

## 4단계: 내보내기

**📥 Excel로 내보내기 (원본 포맷 유지)** 를 누릅니다. `keywords_results_<날짜>.xlsx` 가 받아집니다.

열어 보면 처음에 만든 워크북 구조가 그대로입니다 — 시트 `AI` 와 `Python`, 1행 헤더도 그대로. 그 아래에 결과 행이 붙었습니다. 2단계에서 정한 헤더 이름이 어느 열로 갔는지 여기서 확인할 수 있습니다.

원본을 새로 쓰지 않고 구조를 보존하는 이유는, 실제 연구에서 쓰는 워크북이 이미 서식·수식·다른 시트를 갖고 있기 때문입니다. 검색 결과만 얹혀야 합니다.

## 만든 것

샘플 2개를 키워드 2개로 훑어 문장·표·이미지 히트를 뽑고, 원본 구조를 지킨 채 Excel로 내보냈습니다. 실제 연구에서도 흐름은 똑같습니다 — 샘플 자리에 문헌 폴더가, 키워드 2개 자리에 30개가 들어갈 뿐입니다.

이제 자기 자료로 해볼 수 있습니다. 문서를 마크다운으로 바꿔 한 폴더에 모으고, 키워드마다 시트를 만든 워크북을 준비하면 됩니다.

## 막혔을 때

**폴더 선택 버튼을 눌러도 아무 일이 없다**
Safari나 Firefox입니다. `showDirectoryPicker` 는 Chromium 계열에만 있습니다. Chrome이나 Edge로 여세요.

**검색 시작 버튼이 계속 회색이다**
키워드와 파일 중 하나가 비어 있습니다. 조건은 `마크다운 파일 > 0개` **그리고** `키워드 > 0개` 입니다. 1·2단계를 각각 다시 확인하세요.

**Excel을 올렸는데 키워드가 안 뜬다**
시트 **탭 이름**이 키워드입니다. 셀에 적은 값이 아닙니다. `Sheet1` 하나만 있는 워크북이면 키워드도 `Sheet1` 하나로 잡힙니다.

**발견된 마크다운 파일이 0개다**
`.md` 와 `.markdown` 만 훑습니다. `.txt` 나 `.pdf` 는 잡지 않습니다 — PDF는 먼저 마크다운으로 변환해야 합니다.

**내보낸 파일에 결과 열이 비어 있다**
1행 헤더 이름이 2단계 표의 별칭 목록에 없는 것입니다. 앱은 아는 이름의 열에만 값을 씁니다.

**포트가 이미 쓰이고 있다**
서버가 3008부터 **10개까지**(3008~3017) 빈 포트를 찾아 올라갑니다. 터미널에 찍힌 주소를 쓰세요. 그 범위가 전부 막혀 있으면 직접 지정하세요 — `python3 outputs/server.py 9000`.
