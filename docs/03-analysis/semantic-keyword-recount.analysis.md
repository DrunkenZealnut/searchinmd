## Occurrence-based analysis

최종 분석의 기본 단위는 페이지가 아니라 문맥이 확인된 키워드·표현의 **출현건수**로 고정했다. 정본(2026-09-14) NCS 12,506건과 교과서 1,293건을 합쳐 전체 13,799건(키워드-표현 매칭 레코드 합계)을 분석 분모로 사용하며, 페이지 수는 원문 위치와 확산 범위를 설명하는 참고값으로만 둔다.

- 기존·유효 정확 표현: 9,875건(71.6%)
- 동등 표현 추가: 2,417건(17.5%)
- 구체 표현 추가: 1,507건(10.9%)
- 문맥 제외: 844건(원문 검색 결과에는 있었으나 의미 출현으로 세지 않음)
- 상위 키워드: 안전 4,499건(32.6%), 화학물질 1,641건(11.9%), 위험 1,373건(9.9%), 보호구 1,312건(9.5%)
- NCS 영역별 출현건수(분모 NCS 12,506건): 반도체재료 6,038건(48.3%), 반도체장비 3,699건(29.6%), 반도체제조 1,595건(12.8%), 반도체개발 1,174건(9.4%)

위 수치는 정본 `docs/03-analysis/data/semantic_summary.json`(2026-09-14)에서 다시 산출한 값이고 세 계층의 합(9,875+2,417+1,507)은 13,799건과 일치한다. 비율은 `해당 출현건수 ÷ 13,799건`이며, 키워드 간 중복 페이지를 제거한 비율이 아니다. (2026-09-09 판: 14,168건 기준 10,218 / 2,390 / 1,560, 안전 4,639건 — 폐기.) 따라서 페이지 수와 출현건수를 섞어 등급이나 페이지 비율을 산출하지 않는다.
