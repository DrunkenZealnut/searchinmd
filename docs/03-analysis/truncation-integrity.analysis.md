## 3. 설계 자체의 결함 2건

Gap 이 구현 쪽에만 있는 것은 아니다.

1. **설계가 F1 을 `strata()` 에 배치했다.** 층별 F1 은 규칙 변형 재실행이 필요해
   `score_variants()` 의 일이다. 설계 §6 을 그대로 따랐다면 `strata()` 안에서
   원본 엑셀을 다시 읽는 잘못된 구조가 나왔을 것이다.
2. **설계가 `page_record` 를 `x['truncated']` 로 적었다.** 기존 테스트 픽스처를
   확인하지 않은 서술이고, 그대로 구현하면 R3a-R3n 이 전부 깨진다.

### 5.1 #25 를 설계대로 구현하지 않은 이유

설계 §6 은 "규칙 대비 F1 을 층별로 낸다" 였다. 구현하려다 두 가지가 걸렸다.

1. **분쟁군은 전수 표집이다.** 절단 9항목을 빼면 더 이상 전수가 아닌데, `score_variants()`
   의 계산은 표본 수치를 **모집단 예측 쪽수**로 나눈다. 층별로 자르는 순간 그 가중이
   어긋나 정밀도·재현율이 의미를 잃는다.
2. **9항목 F1 은 판별력이 없다.** 신뢰구간 폭이 변형 간 차이(0.02~0.04)보다 넓다 —
   `TODOS.md` 가 이미 전체 표본에 대해 기록한 문제가 층에서는 더 심해진다.

대신 **분쟁군의 '수정본 지지율'을 절단 포함/제외로 병기**한다. 비율이라 표본이 줄어도
해석이 유지되고, 두 값이 벌어지면 "수정본 우세가 절단 인공물" 이라는 가설이 바로 읽힌다.
배치도 `score_variants()` 가 아니라 `strata()` 가 맞다 — 규칙 변형 재실행이 필요 없다.
설계 §6 에 정정 배너를 달았다.

`kappa` 의 nan 가드 둘, `strata` 의 미도달 분기 둘, `chunk_text` 의 줄 경계 폴백,

### 5.4 남은 것

- **독립성은 여전히 미해결.** Act-1 도 같은 주체가 수행했다. §0 의 경고는 유효하다.
  다만 Act-2 의 커버리지·계획 감사는 독립 서브에이전트가 수행했고, 둘 다 이 문서의
  "100%" 주장을 검증 대상으로 삼았다.
- `truncation_audit.py` 는 R12p-R12p5·R13a-R13i 로 덮였다. 실 워크북 대조는 여전히
  `data/` 가 있어야만 돌지만, 실행 시 `EXPECTED` 불일치면 exit 1 이라 자체 회귀도 한다.
- 대시보드는 `절단` 열을 아직 쓰지 않는다. 설계 범위 밖이며, 표시 여부는 §6 결정 1
  (제외 / 층화 / 각주)이 정해진 뒤에 판단할 일이다.
