## 2. 등급 코딩이 데이터셋마다 다르다

등급사유 문자열을 전수 분류한 결과 각 등급의 의미가 100% 일관되게 확정된다.

| 데이터셋 | 등급1 | 등급2 | 등급3 |
|---|---|---|---|
| NCS 7,769 | `키워드 N건 (5건 이하)` → **미흡·없음** | `…구체적 조치 언급 없음` → **형식적** | `…+ 조치 M건` → **구체적** |
| 교과서 981 | `…(구체적 대책 미흡)` → **형식적** | `…(구체적 대책 포함)` → **구체적** | `키워드 N건 (5건 이하)` → **미흡·없음** |
| 구버전 3,552 | `…조치/대책 언급 없음` → **형식적** | `…+ 조치/대책 M건` → **구체적** | `5건 이하 / 키워드 없음` → **미흡·없음** |

각 대시보드의 라벨은 자기 원본에 대해 정확했다. 근본 원인은 **NCS 7,769 재수집 시 등급 코딩이 뒤집힌 것**이다.
`docs/01-plan/features/safety-grading.plan.md`(1=기본언급/2=구체적대책/3=관련없음)와
`docs/01-plan/features/feature-proposals.plan.md`(1=관련없음/2=기본언급/3=구체적대책)의 서술 충돌도 이 때문이다.

**통일 등급체계**: `1 미흡·없음 / 2 형식적 언급 / 3 구체적 대책`. 교과서는 `{1→2, 2→3, 3→1}`로 재매핑한다.

## 3. 등급은 페이지 속성인데 행 단위로 집계돼 있었다

같은 (교재, 페이지)의 모든 키워드 행이 사실상 같은 등급을 갖는다 — NCS 1,847쪽 중 등급이 갈린 페이지는 12쪽(0.6%), 교과서 362쪽 중 **0쪽**.
따라서 행(키워드×쪽) 단위 집계는 한 페이지에 걸린 키워드 수만큼 중복 계수되며, **안전 내용이 많은 페이지일수록 키워드가 많이 걸리므로 상위 등급이 체계적으로 과대평가**된다.

**혼재 12쪽의 해소 규칙 — 충돌 시 최저 등급.** 다수결은 쓸 수 없다. 갈리는 12쪽은 전부 §6의 `인화` 등 총계 부풀림 버그가 원인인데, 같은 오류 판정이 여러 행에 중복 기록되거나(`LM1903060425` p.28 은 4:1) 같은 오류의 변형이 둘로 갈려(`LM1903060416` p.83 은 "안전 6건"과 "안전 8건") 정확한 행을 이긴다. 중복 수와 변형 수는 정확성과 무관하다. "총계 == 내역 합" 검사도 쓸 수 없다 — 사유 문자열이 상위 키워드만 싣고 잘리는 정상 행이 41%다. 최저 등급 규칙은 판정을 스캔 순서에서 완전히 분리하고, 안전 내용을 과대평가하지 않는 방향이다. 이 규칙으로 3쪽이 등급2 → 등급1 로 이동한다(전부 반도체재료). 페이지별 등급 배정 전체는 `summary.json` 의 `page_grade_digest` 로 고정돼, 총계가 상쇄되는 재배정도 회귀 검증에서 잡힌다.

| NCS | 페이지 | 행 | 증폭 |
|---|---|---|---|
| 등급1 미흡·없음 | 1,270쪽 (68.8%) | 2,076건 (26.7%) | 1.6배 |
| 등급2 형식적 | 469쪽 (25.4%) | 3,465건 (44.6%) | 7.4배 |
| **등급3 구체적** | **108쪽 (5.8%)** | **2,228건 (28.7%)** | **20.6배** |

**"NCS 구체적 대책 28.7%"의 실제 값은 5.8%다.**
