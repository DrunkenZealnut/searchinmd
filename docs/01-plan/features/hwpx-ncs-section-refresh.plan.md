## 1. 개요

### 1.1 목적

`data/반도체 기초보고서_20260911.hwpx` 제3장 1절(교과서)·2절(NCS)·3절(사고·부상·질병 사례)의 숫자 데이터·표·그래프를 전부 정본(2026-09-14, 사전 v2; 사고사례는 재세그먼트 검증)으로 바꾼다. 다른 절은 바이트 단위로 그대로 둔다.

### 1.2 배경

- 정본은 `semantic_keyword_recount.py` 의 2026-09-14 실행(`docs/03-analysis/data/semantic_summary.json`, `EXPECTED` 가드, 사전 v2 — 결정 3): NCS 86권 **11,517건**, 등급 1/2/3 = 4,378 / 4,614 / 2,525(**21.9%**), 미확정 0; 교과서 9권 1,207건. 분야: 반도체개발 30권 1,110건(9.6%), 제조 13권 1,328건(11.5%), 장비 19권 3,239건(28.1%), 재료 24권 5,840건(50.7%).
- 보고서 2절은 2026-09-09 실행의 값(12,875건·813 미확정·85종)이다. 이 실행은 외부감사(2026-09-13, 등급 F) C1(변환기 요약본 4개·중복 1개가 교재로 계수)로 폐기됐고, 그 뒤 결정 1(결함 2건, v1fix)·결정 2·3(표현 점검, v2)까지 세 번 바뀌었다.
- 같은 문서를 대상으로 한 이전 작업(`update_hwpx_report.py`·`rebuild_hwpx_tables.py`, 2026-09-10~11, Codex, 미추적)은 다른 파생본(`교정-교정-…_표그래프교체_20260910.hwpx` 등)에 2026-09-09 값을 넣은 것이라 이 문서·이 정본에는 그대로 못 쓴다. 표 교체·SVG→BMP·ZIP 재작성 패턴은 참고한다(D4).
