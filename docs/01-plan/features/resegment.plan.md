| **Function/UX Effect** | `resegment.py` 가 `ncs_pages_reseg.csv`·`reseg_summary.json` 과 구 라벨→실제 쪽 대응표를 쓰고, 보고서 표 11·12·그림 3·4·분야별 문장·사고사례 쪽 번호를 이 수치로 갱신한다. 대시보드 재발행 여부는 별도 판단. |

## 1. Overview

### 1.1 Purpose

워크북 라벨(TOC 블록) 기준의 페이지 집계를 실제 PDF 쪽 기준으로 바꾼다. 검출 행(키워드 적중) 자체는 그대로 두고 **쪽 배치와 쪽 본문, 그에 따른 등급만** 다시 계산한다.

### 1.2 Background

- 외부감사(2026-09-04) C1: 워크북 페이지 본문 길이 중앙값 1,066자인데 16개 라벨이 32,767자. 『반도체 장비 안전관리』 776행 중 774행이 실제 쪽과 3쪽 이상 어긋남. "셀 한도 절단 16쪽" 은 이 블록의 증상.
- 시제품(2026-09-06): 워크북 7,769행의 매칭 문장을 현재 마크다운에서 찾으면 6,082행(78%)이 유일 매칭, 그중 5,072행이 라벨과 다른 마커 쪽으로 이동. 81권 중 80권에서 이동 발생. 그러나 현재 마크다운 마커는 66권이 목차 유도(쪽당 마커 아님)라 그 자체가 기준이 될 수 없다.
- PDF 원본은 `~/DEV/SemiconductorAcademy/data/ncs/` (`NCS_PDF_ROOT`) 에 파일 88개, 그중 LM 코드가 있는 것 86개(워크북 86권 전부; 나머지 2개는 `report.pdf` 류라 `meta.pdf_files` 는 86). 마크다운은 89개 파일·84개 코드라 **마크다운 없는 2권**은 라벨 그대로 두고 `unresolved` 로 표시한다.
- 연구 책임자 결정(2026-09-06): 재집계 A, 재코딩 수치는 보고서에 싣지 않음, 표 13 에 재료 안전관리 p.28 행 추가, 『반도체 인프라 일반』 p.155 TMAH 는 사고사례로 계수.

### 1.3 Related Documents

## 2. Scope

### 2.1 In Scope

- [x] `resegment.py`: PDF 쪽 텍스트(PyMuPDF) ↔ 마크다운 줄 단조 DP 정렬, 줄→쪽 대응, 미정렬 줄 전파
- [x] 워크북 행 → 마크다운 줄 매칭(매칭 문장 정규화, 같은 문장 반복은 문서 순서로 배정), 행 → 실제 쪽
- [x] 실제 쪽 본문 → `regrade.grade_page`(기준선) 등급, 사고사례 플래그(행 OR), 영역·교재별 집계
- [x] 산출물: `docs/03-analysis/data/ncs_pages_reseg.csv`, `reseg_summary.json`(분포·영역·교재·정렬 품질·미해결 수), 구→신 대응표
- [x] 정렬 정확도 자체 검증: 쪽 단위 마커가 있는 교재(마크다운 89개 중 23개, 전부 워크북에 있는 교재)에서 정렬 결과와 마커를 대조해 정확·±1 비율을 기록 — Check-1 실행에서는 `pick_md` 동점 처리가 마커 없는 중복 파일을 골라 22권만 검증됐고(Gap G16), Act-2 에서 마커 수로 동점을 가려 23권이 됐다
- [x] 하니스 `R16` (합성 픽스처, PDF·워크북 없이): 정렬 DP·전파·행 매칭·집계·요약 스키마
- [x] 분석 문서 `docs/03-analysis/resegment-results.analysis.md`(구 vs 신 분포, 이동 패턴, 사고사례 8쪽 실제 쪽, 한계)
- [x] 보고서(0905본) 표 11·12·그림 3·4·분야별 문장·3절 쪽 번호를 신 수치로 갱신(재수정 목록 [재집계] 항목)

### 2.2 Out of Scope

- 검색(키워드 적중) 재실행 — 행 집합은 워크북 그대로. 새 키워드나 새 적중은 만들지 않는다
- 대시보드(`docs/*.html`)·README 수치 교체 — 연구 책임자 판단 후 별도 작업
- 반도체고 교과서 워크북 — 감사에서 유일 매칭 245행 전부 일치, 재세그먼트 불필요
- PDF 재변환(marker 재실행) — 워크북 문장과 새 OCR 이 어긋나 행 매칭이 깨진다
- 등급 규칙 변경(D1·D2·V 변형 채택) — 기준선 규칙만 쓴다

## 3. Requirements

### 3.1 Functional Requirements

| ID | Requirement | Priority | Status |
|----|-------------|----------|--------|
| FR-01 | 마크다운 줄을 PDF 쪽에 단조(비감소) 정렬한다. 줄의 문자 3-gram 이 쪽 텍스트에 50% 미만 포함되면 미정렬로 두고 이웃 정렬 줄의 쪽을 물려받는다 | High | Done (`align_lines`·`propagate`, R16b·c) |
| FR-02 | 쪽 단위 마커가 있는 책에서 정렬 결과를 마커와 대조해 정확·±1 비율을 `reseg_summary.json` 에 기록한다(자기 검증) | High | Done (`check_alignment`, `alignment_check`, R16g) |
| FR-03 | 워크북 행의 매칭 문장(`contents` 마지막 줄)을 정규화해 마크다운 줄에 붙인다. 같은 문장이 파일에 k번, 행이 k번이면 문서 순서로 1:1 배정. 못 찾은 행은 `unmatched` 로 표시하고 구 라벨을 유지한다 | High | Done (`match_rows`, R16d; 미매칭 94행) |
| FR-04 | 실제 쪽 본문(정렬로 그 쪽에 속한 줄)에 `regrade.grade_page(text)` 기준선을 적용해 등급·사유를 만든다. 셀 한도 절단은 발생하지 않는다(엑셀을 거치지 않음) | High | Done (`regrade_page`, R16e) |
| FR-05 | 페이지 단위 집계(교재·영역·등급·사고사례)를 구 산출물(`summary.json`)과 같은 스키마로 쓰고, 구→신 대응(라벨→실제 쪽 목록, 이동 행 수)을 남긴다 | High | Done (`aggregate`, `rows_map.csv`, CSV `구라벨`, R16f·j) |
| FR-06 | 마크다운 또는 PDF 가 없는 책은 구 라벨·구 등급을 그대로 쓰고 `unresolved` 로 센다. 총계에 그 수를 병기한다 | Medium | Done (`unresolved_pages`, R16l·n) |
| FR-07 | 사고사례 판정이 붙은 구 라벨 8개의 실제 쪽을 별도 표로 낸다(감사 C1(c)·3절 갱신용) — 라벨 하나가 여러 쪽을 묶고 있어 실제 쪽은 8개보다 많다 | Medium | Done (`case_pages`, 결과 문서 §3.4 — 구 라벨 8개 → 실제 13쪽/5권) |
| FR-08 | 실행 재현: `python3.13 resegment.py --pdf-root <dir> --md-root data/markdown/ncs --workbook data/…xlsx --out docs/03-analysis/data/`; 기본 경로는 환경변수 `NCS_PDF_ROOT`. 입력이 바뀌면 `--force` 로 쓰고 `EXPECTED` 갱신 | Medium | Done (약 30초, R16h·n) |

## 4. Success Criteria

- [x] 84권의 행이 실제 쪽에 배치되고 미매칭 행 비율 ≤ 10% (1.2%)
- [~] 자기 검증 정확도 83.6%/94.9% — 3.2 기준(85/97) 소폭 미달, 책별 수치는 `alignment_check.per_book`
- [x] 구 vs 신 등급 분포와 이동 원인(블록 해소)이 분석 문서에 설명된다
- [x] 보고서 [재집계] 항목이 신 수치로 채워지고 "108~112쪽" 같은 거짓 정밀도가 없다

## 5. Risks

| Risk | Impact | Mitigation |
|------|--------|-----------|
| PDF 텍스트 레이어와 OCR 마크다운의 차이로 정렬 실패 | 줄이 엉뚱한 쪽으로 감 | 3-gram 포함률 임계 + 단조 제약 + 창 밖 점프 벌점; 마커 보유 23권으로 검증 |
| 문장이 쪽 경계에 걸침 | 그 줄은 한 쪽에만 속함 | ±1쪽 오차로 기록, 등급에 미치는 영향은 분포 수준에서 작음 |
| 기준선 규칙이 원본 채점기와 0.4% 다름 | 신 등급은 "규칙 재적용" 결과 | 문서에 명시. 원본 등급과의 비교는 미이동 쪽에서만 |
| 미해결 2권(md 없음) | 총계 혼합 | `unresolved` 병기, 감사 대상에서 제외하지 않음 |
