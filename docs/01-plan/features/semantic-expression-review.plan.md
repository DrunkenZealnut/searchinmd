# 의미 표현 사전 도메인 점검 계획

> **Summary**: LLM(Codex)이 단독으로 정한 의미 재검산 사전(포함 75·보류 19·제외 2·미출현 4)을 사람이 검증할 수 있게 만든다 — 명백한 규칙 위반 2건은 고치고, 고빈도·의심 표현은 문맥 표본을 뽑아 정밀도를 재고, 그 결과로 사전 v2 변형과 영향표를 낸다. 채택은 연구책임자 결정.

## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 정본 13,799건 중 28.4%(동등 2,417 + 구체 1,507 = 3,924)는 LLM이 혼자 고른 표현이 만든 값이고, 검토·서명 기록이 없다(감사 M1·m3, 연구책임자 "점검 필요"). 실측 반례: 교과서 `PSM` 13건은 전부 Phase Shift Mask, `안전성`은 보류인데 `안전` 정확 규칙 안에서 140건이 세어지고, `방진복`·`장갑`·`방진화`(497건)는 클린룸 오염 방지복일 때가 많으며, `X선` 115건 중 계측(XRD/XRF) 문맥이 섞여 있다. 상위 4개 키워드가 모두 걸려 있다. |
| **Solution** | ① 설계 명세 자체를 위반한 2건(영문 정확 키워드 단어 경계, 보류 표현이 정확 규칙 안에서 계수)은 결함으로 고친다. ② 고빈도(≥50건)·감사 지목 표현 약 20개에 대해 표현당 30건 층화 표본을 뽑아 2계열 AI 코더 + 연구책임자 재정으로 "안전 문맥인가"를 판정하고 정밀도와 95% 구간을 계산한다. ③ 하한 < 0.8 인 표현은 보류 또는 조건부(안전 문맥 동반어)로 바꾼 **사전 v2 변형**을 만들고 v1 대비 영향표(총계·키워드·등급)를 낸다. 채택 시 정본을 재실행해 `EXPECTED`를 재고정한다. |
| **Function/UX Effect** | 포함 표현마다 정밀도·표본·판정자·근거가 남아 "왜 이 표현이 들어갔나"에 답할 수 있고, 대시보드 수치의 확장분(28.4%)이 검증된 값이 된다. 판정 시트는 본문을 담으므로 비추적, 키·수치만 추적. |
| **Core Value** | 사전 채택의 주체가 LLM 단독에서 "측정 + 연구책임자"로 바뀐다 — 감사 M1·m3 종결. |

## 1. 개요

### 1.1 목적

`semantic_keyword_recount.py`의 `default_candidate_decisions()`(사전 v1, `rule_sha256` `2da5dbf4…`)을 검증 가능한 상태로 만들고, 재검산 확장분의 정밀도를 처음으로 측정한다.

### 1.2 배경

- 외부감사(2026-09-13) **M1**: 동음이의 제외·확장 채택 기준이 실제 규칙과 어긋나는 사례 실측 (a)~(e). **m3**: 사전 채택 주체 Codex 단독, 검토 기록 없음, 후보 발견 단계 산출물 미보존.
- 연구책임자 결정 Q5(2026-09-13): "확인함. 포함 범위는 LLM이 결정 — 점검이 필요함."
- `semantic-recount-remediation`(PR #15, 2026-09-14 머지)은 코퍼스·가드·수치 정합을 닫았고 사전은 **v1 그대로** 정본을 돌렸다(`TODOS.md` 이월 1번). 사전이 바뀌면 `rule_sha256`이 바뀌어 가드가 막으므로, 이 기능은 **변형 → 영향표 → 결정 → 재고정** 순서로 간다(`regrade.py` 변형·`resegment.py --marker-correct` 와 같은 규약).

### 1.3 실측 (정본 2026-09-14, `data/semantic_keyword_recount_20260914.xlsx`)

| 감사 지목 | 표현 (키워드) | 정본 출현 NCS / 교과서 | 문제 |
|---|---|---:|---|
| (a) | `PSM` 정확 | 7 / 13 | 정확 규칙이 `re.escape`만 써 단어 경계 없음 → `EAPSM`·`Htpsm` 내부 문자열. 교과서 13건 전부 Phase Shift Mask. `MSDS`도 같은 구조 |
| (b) | `안전` 정확 안의 `안전성` | 140 (+`안전 마진/여유/재고` 32) | `안전성`은 **보류**인데 정확 규칙 내부에서 그대로 계수 — 보류 결정이 계수에 효과 없음 |
| (c) | `방진복` / `장갑` / `방진화` (보호구 구체) | 130·228·72 / 35·29·3 | 반도체 클린룸에서 방진복은 제품 오염 방지복 — 노동자 보호구 문맥과 구분 안 됨. 보호구 확장 +1,028(NCS) 의 절반 |
| (d) | `X선` (방사선 구체) | 97 / 18 | XRD·XRF·X선 회절 등 계측 문맥(감사 실측 39건). `자외선`은 같은 이유로 보류 — 일관성 부재 |
| (e) | `가연성`·`combustible` (인화 동등) vs `발화성` 보류 | 322 / 5 | 계층 판정 기준 불일치 |

비정확 표현 중 출현 ≥ 50건: `화학 물질` 598, `케미컬` 500, `가연성` 327, `장갑` 257, `화학약품` 203, `건강` 171, `방진복` 165, `누설` 136, `작업 환경` 118, `물질 안전 보건 자료` 115, `X선` 115, `화상` 97, `방진화` 75, `유해요인` 60, `개인 보호 장비` 56, `보호안경` 53, `안전화` 53, `보호장구` 50 — 18개. 여기에 (a)(e)의 `PSM`·`combustible`·`발화성`(보류)·`자외선`(보류)을 더한 약 22개가 점검 대상이다.

보류 19개 중 영문 일반어(`safety`·`health`·`risk`·`chemical`·`dust`·`vibration`·`fall`·`leakage`·`safety and health`)는 "보류" 정책이 일관되나 문서화된 기준이 없다.

## 2. 범위

### 2.1 포함

- [ ] **결함 수정 2건 (정본에 바로 반영 후보)** — (a) 영문 정확 키워드(`PSM`·`MSDS`)에 `_ascii_term()` 단어 경계 적용; (b) 보류 표현이 정확 규칙 안에서 계수되지 않도록 `안전` 정확 규칙에 `안전성|안전\s*(마진|여유|재고|율|계수)` 제외 패턴 — 제외 건수는 `동음이의 제외` 열로 보고. 두 건은 설계 명세("부분 문자열 제외", "보류는 계수하지 않음")의 위반이므로 판정 표본 없이 고친다. 단 `rule_sha256`이 바뀌므로 **정본 반영 여부는 연구책임자 결정 사항**(§6 결정 1).
- [ ] **점검 표본** — 대상 표현 약 22개(§1.3), 표현당 30건 층화 무작위(NCS/교과서 출현 비례, 50건 미만 표현은 전수), seed 고정. 표본 시트 `data/expression_review_sheet.{json,md}`(본문 문맥 포함, **gitignore**) + 키 `docs/03-analysis/data/expression_review_key.json`(표현·출처 파일·줄·판정 없음, 추적). `make_coding_sheet.py` 규약을 따른다 — 시트에 계층·판정 근거를 싣지 않는다(앵커링 방지).
- [ ] **판정** — 질문 하나: "이 문맥에서 이 표현은 노동자 안전·보건 의미인가 (O / X / ?)". AI 코더 2계열(`code_pages.py`: `claude-cli` + OpenAI 호환) → 불일치 건은 연구책임자 재정. 결과 `docs/03-analysis/data/expression_review_{A,B,adj}.json`(라벨만, 추적).
- [ ] **정밀도** — 표현별 O 비율과 정확 이항 95% 구간(`score_coding.ALPHA` 재사용), 코더 일치도(κ). 판정 기준: 구간 **하한 < 0.8 → 보류 또는 조건부**, 하한 ≥ 0.8 → 유지. 조건부 = 같은 줄 또는 ±1줄에 안전 문맥 동반어(착용·보호·노출·피폭·화상·부상·위험 등 — 목록은 판정 결과에서 귀납)가 있을 때만 계수.
- [ ] **사전 v2 변형 + 영향표** — `default_candidate_decisions(version="v2")`와 `--dictionary v2`(추적 산출물 경로·기본 출력 거부, `EXPECTED` 불일치는 기록만 — `--marker-correct` 규약). 영향표: 총계·키워드별·등급 분포 v1 vs v2, 결함 수정 2건만 적용한 "v1+결함" 열 별도. `docs/03-analysis/data/expression_review_impact.json`(추적) + `docs/03-analysis/expression-review.analysis.md`.
- [ ] **보류 정책 문서화** — 영문 일반어·계측 문맥어·오염관리어의 보류 기준을 설계 명세에 명문화(자외선 vs X선 같은 불일치 해소).
- [ ] **테스트** — 결함 수정 2건(PSM 부분문자열 0건, 안전성 제외), 표본 추출 결정론(seed·층화 비율), 정밀도 구간, 조건부 규칙, `--dictionary v2` 경로 거부, v1 `rule_sha256` 불변(채택 전). `test_semantic_keyword_recount.py` 확장.
- [ ] **채택 시 Act** — 연구책임자가 v2(또는 v1+결함)를 채택하면 정본 재실행 `--force` → `EXPECTED` 재고정 → 대시보드·README·CLAUDE.md·브리지 표 갱신(하니스 S1~S9가 잡는다). 미채택이면 변형과 영향표만 남긴다.

- 30개 기존 키워드의 병합·상호 확장·새 키워드 추가(설계 명세 불변 규칙).
- 등급 규칙(`regrade.grade_page`)·분모(출현건수) 변경.
- 페이지 단위 이질성(M2), 비단조 마커 재유도, `public_path` 통합, hwpx 문서 수치 — `TODOS.md` 다른 이월 항목.
- 사람 이중코딩 30~40쪽(등급 규칙 검증용, `TODOS.md` P2) — 별개 트랙.
