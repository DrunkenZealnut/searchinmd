# 의미 단위 키워드 재검산 계획

> **2026-09-14 정본 갱신 (semantic-recount-remediation).** 아래 2026-09-09 수치는 코퍼스가 오염된 실행(NCS 89파일 = 교재 84 + 변환기 요약본 4 + 중복 1)의 값이라 **폐기**됐다. 정본은 NCS 86권(2026-09-13 추가 2권 포함)·교과서 9권을 `data_source/markdown` 에서 읽은 2026-09-14 실행이며, 수치는 `docs/03-analysis/data/semantic_summary.json` 이 원본이다. 갱신된 표에는 "정본" 표기가 있다. 외부감사(2026-09-13, 등급 F)와 연구책임자 결정 8건은 `docs/archive/2026-09/semantic-recount-remediation/semantic-recount-remediation.plan.md` §1.2.

## 1. 목표

- 30개 기존 키워드 각각에 대해 포함·보류·제외 표현 기준을 만든다.
- NCS 86권(정본 2026-09-14; 2026-09-09 판의 "89개"는 요약본 4·중복 1을 포함한 오염 코퍼스)과 교과서 9개 Markdown에서 정확 문자열, 동음이의 제외, 동등 표현, 구체 표현을 전수 계수한다.
- 모든 결과를 원문 위치까지 역추적할 수 있는 XLSX와 Markdown 보고서로 만든다.
- 같은 입력과 사전으로 재실행하면 같은 해시와 집계가 나오도록 한다.

## 2. 범위

### 포함

- 원본 워크북의 30개 시트명과 시트별 실제 검색행 수
- `data/markdown/ncs/**/*.md`와 `data/markdown/school-text/**/*.md`
- 키워드별 독립 의미 사전, 문맥 제외 규칙, 전체 매칭 상세
- 파일별·키워드별·표현별 집계와 결과 보고서

### 제외

- 기존 키워드 간 병합, 상호 확장, 개념군 또는 전체 통합 합계
- 원본 워크북의 30개 상세 시트 복제
- 외부 웹 문헌을 근거로 원문에 없는 표현 추가
- 등급 재판정 및 기존 대시보드 발표 수치 변경

## 3. 성공 기준

- [x] 키워드 30개, NCS 86권, 교과서 9개를 모두 처리한다 (`EXPECTED["documents"]` 가 고정).
- [x] 원문 정확 문자열과 독립 단순 검색 값이 일치한다.
- [x] 신규 표현은 하나의 기존 키워드에만 귀속된다.
- [x] 모든 상세행에 파일·줄·페이지·문맥이 있다.
- [x] 요약, 표현별, 파일별, 상세행 집계가 일치한다.
- [x] XLSX 무결성 검사와 독립 2회 생성 해시 비교를 통과한다.
- [x] 키워드별 포함·보류·제외 표현이 보고서에 모두 제시된다.

## 4. 위험과 대응

| 위험 | 대응 |
|---|---|
| 동음이의로 과대 계수 | 정확 문자열도 문맥 제외 규칙을 적용하고 제외 건수를 별도 보고 |
| 임의적 의미 확장 | `동등`·`구체` 계층과 근거를 분리하고 애매하면 보류 |
| 기존 키워드 통합 | 다른 29개 키워드 문자열을 확장 사전에서 자동 거부 |
| 페이지 마커 없음 | 정본 코퍼스에서는 마커 없는 파일이 중복 1개뿐(중복 제거로 소멸); 남는 출현 1건은 문맥 판정 (2026-09-13 승인) |
| 원본 워크북 헤더 예외 | `사망` 시트를 포함해 행 내용으로 헤더 여부 판정 |
| 결과 재현 불가 | 입력·사전·상세행 SHA-256과 생성 명령 기록 |
