# 의미 출현 등급 결합 계획

## 1. 목적

재검산 xlsx(정본 `semantic_keyword_recount_20260914.xlsx`)의 NCS·교과서 의미 출현마다 기존 페이지 등급(등급1~3)을 결합하고, 두 대시보드를 동일한 교과서 분석 흐름과 출현건수 기준으로 통일한다.

## 2. 범위

### 포함

- 기존 페이지 등급을 문서·페이지 키로 의미 출현에 상속
- 새로 검출된 페이지는 기존 기준선 판정 함수로 등급 계산
- 페이지 마커가 없는 출현은 그 줄의 문맥으로 판정하고 문맥이 비면 등급1 (연구책임자 승인 2026-09-13 — 미배정을 두지 않는다; 2026-09-09 판은 `등급 미확정` 분리였음)
- 재검산 Excel 상세·파일별·요약 시트에 등급과 판정 출처 추가
- NCS·교과서 페이지를 등급 KPI → 전체 분포 → 키워드 상세 → 문서/영역 → 시사점 → 비교 → 권고 순으로 통일
- 등급 분포와 비교값의 분모를 의미 출현건수로 통일

### 제외

- 기존 원본 Excel 직접 수정
- 등급 정의나 임계값 변경
- 보류·제외 표현을 출현건수에 포함

## 3. 성공 기준

- [x] 모든 페이지 확인 가능 출현에 등급1~3, 등급명, 사유, 출처가 있다.
- [x] 페이지 마커가 없는 출현도 등급을 받아 `grade_unpaged` 가 0 이다 (승인 2026-09-13; 정본 1건). 2026-09-09 판의 "미확정 보존·분모 제외"는 폐기.
- [x] 등급별 출현건수 합이 등급 확정 출현건수와 일치한다.
- [x] 기존 페이지는 기존 등급을 보존하고 신규 페이지만 재판정한다.
- [x] NCS와 교과서 대시보드는 동일한 섹션 순서와 등급1~3 표현을 쓴다.
- [x] 기존 및 신규 회귀 테스트가 모두 통과한다.

## 4. 위험과 대응

| 위험 | 대응 |
|---|---|
| NCS 문서명과 현재 Markdown 파일명 형식 차이 | NCS 능력단위 코드를 우선 키로 삼고 Unicode·타임스탬프·확장자를 정규화 |
| 교과서 원본의 반대 등급 코드 | 기존 교과서 Excel을 읽을 때 통일 등급 1→3으로 재매핑 |
| 신규 페이지 등급 누락 | Markdown 페이지 전체에 `regrade.grade_page()` 기준선 적용 |
| 페이지 없는 대형 문서가 분포를 왜곡 | 코퍼스 정제(LM 코드 필수·중복 제거)로 그런 문서가 없어졌다. 남는 마커 없는 출현은 문맥 판정 |
| 원본과 산출물 혼동 | 원본은 읽기 전용으로 두고 재검산 Excel만 재생성 |
