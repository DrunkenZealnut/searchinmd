## 1. 개요

### 1.1 목적

`hwpx_results_refresh.py` 를 확장해, 정본 HWPX 에 (A) 제2장 5절 연구 방법의 실제 2026-09 방법 서술과 (B3) 제3장 2절의 집계 기준 변경·이전 기준 연결 소절을 데이터에서 생성한다. 다른 문단·ZIP 항목은 바이트 단위로 그대로 둔다.

### 1.2 배경

- 제안서 `docs/04-report/features/research-content-proposals-20260915.md` 의 A·B3 를 연구책임자가 선택했고(2026-09-16 "A+B3"), 문안 초안은 `research-content-draft-A-B3-20260916.md` 에 있다(수치 출처 표기 완료). 이 계획은 그 초안을 **스크립트 템플릿**으로 옮기는 일이다.
- 1단계(`hwpx-ncs-section-refresh`, 2026-09-14~15)의 규약을 잇는다: 원본 `…_20260911.hwpx` 에서만 실행(정본 파일은 입력이 아니다 — 문단 탐지가 원본의 첫 단어에 묶여 있음), 출력 이름은 정본 실행일(`…_20260915_정본.hwpx`), 대조 JSON `hwpx_results_refresh_20260915.json`, 검토 HTML 은 표·그림만, 구/신 문장은 `data/` 비추적.
- 정본 파일은 2026-09-15 이후 한글에서 다시 저장됐다(`lineseg`·ZIP 메타만 다름, 본문·표·그림 동일 — 세션 검증). 2단계 출력이 같은 이름을 쓰면 이 파일을 덮어쓴다(D1).
- 제3장 2절 "3)과 4) 부분은 1절과 완벽하게 똑같습니다…" 같은 검토 메모 문단과 각주 중복은 이 기능 밖(제안서 §4).
