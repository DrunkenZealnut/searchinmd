### Design

**아키텍처 결정**
- **정렬 우선순위**: 마커 있는 책은 마커 우선(변환기 신뢰), 없는 책은 DP 배정
- **미정렬 줄 처리**: 직전 정렬 줄의 쪽 물려받기 (propagate)
- **행 매칭**: 매칭 문장 정규화, 같은 문장 반복은 문서 순서로 배정
- **회귀 방어**: `page_grade_digest` + EXPECTED 레지스트리로 무음 변경 차단

**함수 계약 (9개 핵심 함수)**
- `align_lines()`: 단조 DP, 창 6쪽, 점프 벌점 0.06, 포함률 임계 0.5
- `marker_pages()`: HTML 주석 `<!-- page: N -->` 파싱
- `match_rows()`: 짧은 키(10자 이상) vs 전체 키(10자 미만 정형구)
- `regrade_page()`: 실제 쪽 본문에 `regrade.grade_page` 기준선 적용
- `propagate()`: 미정렬 줄 → 직전 정렬 줄 쪽 상속

   - 한 수치 변경도 지문이 뒤따름 → 무음 오류 불가
   - 다음 재계산 시 같은 구조 재사용 가능

2. **정확도 분리 (후보 줄 vs 전체 줄)**
   - 정렬 결과(후보)와 전파(미정렬)를 분리 → 정확도 현실적 표기
   - 61권의 정렬 정확도 미측정 한계를 명시하지 않으면 과장 위험

3. **출하 전 다층 리뷰**
   - 적대적 리뷰 11건으로 파라미터 민감도, 경계 오차 등 검증
