## 구현 교훈

### 설계에서 실무까지의 편차 처리

**D1: 이웃 순서 제약의 실무 수정**
- 설계 초안: 엄격(이웃 마커 쪽 사이에 들어야 함) → 구현: 비감소(같은 쪽 허용), 설계 반영판 §0 에 근거 기록
