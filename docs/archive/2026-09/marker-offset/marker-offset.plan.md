## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | 재세그먼트는 쪽 단위 마커가 촘촘한 23권(마커 방식)에서 변환기가 찍은 마커를 그대로 쪽 번호로 쓴다. 그런데 마커 자체가 ±1쪽 밀린 경우가 있다 — 『반도체 장비 안전관리』 마커 쪽의 md 본문을 PDF 인접 쪽과 3-gram 대조하면 151쪽 중 64%만 같은 쪽과 가장 잘 맞고 23%는 +1쪽과 더 잘 맞는다. 이 책은 등급3 145쪽 중 42쪽·사고사례 13쪽 중 8쪽을 차지해, 발표 쪽 번호(예: 사고사례 쪽 112 — PDF 113 과 더 잘 맞음, 수기 표는 113)가 마커 오차를 그대로 물려받는다. 자기 검증(`nogap_*` 88.6%)도 마커를 정답으로 삼아 이 오차를 DP 오류로 계상한다. |
| **Solution** | ① DP 와 독립인 측정 — 마커 교재 23권 전부에서 마커 쪽별 md 본문 3-gram 포함률을 PDF P−k..P+k 와 대조해 최적 오프셋 분포를 산출물에 남긴다(교재·쪽 단위, 발표 수치는 건드리지 않음). ② 보정 규칙 후보(인접 쪽 포함률이 같은 쪽보다 뚜렷이 높을 때만 그 쪽으로 옮김; 임계·최소 본문 길이·구간 단조 유지)를 변형으로 구현해 영향(쪽 수·등급 분포·사고사례 쪽·등급3 42쪽의 이동)을 표로 낸다. ③ 연구 책임자가 채택 여부를 정하면 `resegment_book` 의 마커 경로에 적용하고 `EXPECTED`·산출물·대시보드·보고서를 갱신한다. |
| **Function UX Effect** | 채택 전에도 CSV/JSON 에 마커 오프셋 진단(교재별 분포, 쪽별 최적 오프셋)이 실려 어느 쪽 번호가 ±1 의심인지 볼 수 있다. 채택하면 마커 교재의 쪽 번호가 PDF 본문에 맞춰지고, 사고사례·등급3 쪽 인용(보고서 표·대시보드 사고사례 표)이 수기 표와 일치하는 방향으로 움직인다. |
| **Core Value** | "±1쪽 수준" 이라고만 적혀 있던 마커 교재의 쪽 오차를 측정값으로 바꾸고, 보정을 하든 안 하든 그 근거가 산출물·`EXPECTED` 가드 안에 남는다. 수치 변경은 측정 → 영향표 → 결정의 순서로만 일어난다. |

## 1. 배경

- 마커 교재(밀도 ≥ `DENSE_MARKER_RATIO` 0.8, 23권)는 `marker_pages` → `hybrid_pages`(결손 구간만 DP) 로 쪽을 정한다. 마커가 없는 쪽만 보정할 뿐 마커가 찍힌 쪽의 번호는 검증하지 않는다.
- PR #14 리뷰(2026-09-06) 실측: 『반도체 장비 안전관리』(154 마커/155쪽, 결손 1쪽) 151쪽 중 오프셋 0 이 96(64%), +1 이 35(23%), −1 이 10, 그 밖 10. DP 대 마커 차이(후보 1,776줄)는 +1 이 467줄(26%), −1 이 221줄(12%) — 즉 자기 검증의 "틀림" 상당수가 DP 가 아니라 마커 쪽 오차다. 사고사례 쪽 112 는 PDF 112 포함률 0.56, PDF 113 은 0.71.
- 이 책 한 권이 발표 수치에서 차지하는 몫이 크다(등급3 42/145, 사고사례 8/13). 다른 22권의 분포는 아직 재지 않았다.
- 결정 기록: 결과 문서 §6 6 "[후속 판단] 마커 교재의 마커 ±1쪽 보정 여부" — 현재는 마커 그대로(한계로 §4 기록).

## 3. 범위 밖

- 정렬 교재 61권(마커가 없거나 성긴 책)의 쪽 번호 — 이미 DP 로 정하며, 이 기능의 대상이 아니다.
- 마커 자체를 마크다운 파일에 다시 쓰는 것(`insert_page_markers.py` 변경) — 산출물 단계에서만 보정한다.
- 판정 규칙·어휘·재검색.

## 4. 성공 기준

- [ ] 마커 교재 23권 전부의 오프셋 분포가 `reseg_summary.json` 에 있고, 『반도체 장비 안전관리』의 값이 리뷰 실측(0: 64%, +1: 23%)과 ±2%p 안에서 재현된다.
- [ ] 변형 실행의 영향표(쪽·등급·사고사례·수기 표 일치)가 결과 문서 §3.7 에 임계별로 있다.
- [ ] 연구 책임자 결정이 §6·TODOS 에 기록되고, 채택 시 대시보드·보고서·`EXPECTED` 가 같은 수치를 인용한다.
- [ ] 하니스 5종 통과, 커버리지 ≥ 80%.

## 5. 위험

| 위험 | 영향 | 대응 |
|---|---|---|
| 그림·표만 있는 쪽은 md 본문이 짧아 포함률이 불안정 | 잘못된 ±1 판정 | 최소 본문 길이 미만은 "모호" 로 두고 옮기지 않음 |
| 같은 문장이 이웃 쪽에 반복(머리글·정형구) | 인접 쪽 포함률이 같은 쪽과 비슷 | 임계 마진 + 두 쪽 포함률 차이 병기, 민감도 표 |
| 보정이 `hybrid_pages` 구간 경계를 바꿈 | 결손 구간 재정의로 쪽 배정 연쇄 변화 | 보정된 마커로 구간을 다시 만들고 `hybrid_emptied_marker_pages` 0 유지 확인 |
| 보정 후 수기 사고사례 표와 더 안 맞을 가능성 | 근거 약화 | 영향표에 일치 수를 넣어 결정 근거로 삼음 |
