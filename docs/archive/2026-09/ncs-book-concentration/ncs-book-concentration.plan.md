# NCS 교재별 등급 3 집중·편차 보강 계획 (제안 B1)

> **Summary**: 정본의 NCS 등급 3 출현 2,502건 가운데 965건(38.6%)이 안전관리 전용 2권(`LM1903060329` 반도체 장비 안전관리 · `LM1903060411` 반도체 재료 안전관리)에 있다. 두 권을 빼면 NCS 합산 등급 3 비율은 21.7% → 16.6%, 장비 분야는 32.5% → 16.9%가 되고, 86권의 파일별 등급 3 비율은 평균 8.5%·중앙값 0.0%, 등급 3 이 0건인 교재가 57권(66.3%)이다. 지금 기초보고서 제3장 2절과 대시보드는 합산 21.7% 만 말하고 "다수 교재 0%" 를 말하지 않는다. 교재 단위 집계를 **정본 JSON(`semantic_summary.json`)의 `corpora.*.books[]` 로 넣고**(D1 b — 정본 재실행), 그 값으로 제3장 2절에 " 5) 교재별 집중과 편차"(표 12-3 집중도 + 표 12-4 상위 교재 + 문단 2)를 스크립트로 생성하며, 대시보드(NCS)에 교재별 표를 낸다.

## 1. 개요

### 1.1 목적

정본 실행 산출물에 **교재(파일) 단위** 집계를 더하고, 그 값으로 기초보고서 제3장 2절에 "교재별 집중·편차" 소절을, 대시보드(NCS)에 교재별 표를 생성한다. 손대지 않은 문단·ZIP 항목은 2단계와 같은 규약(손댄 문단 장부, 숫자 감사, 바이트 불변)으로 지킨다.

### 1.2 배경

- 제안서 `docs/04-report/features/research-content-proposals-20260915.md`(비추적) §B1 — 연구책임자가 2026-09-17 "후속 B1" 로 선택. 문안 초안은 `data/semantic_keyword_recount_20260915_file_insights.md` §2·§7(비추적).
- 근거 수치는 정본 워크북 `data/semantic_keyword_recount_20260915.xlsx` 의 `NCS_파일별` 시트를 세션에서 재집계해 확인했다(2026-09-17): 86권 11,517건·등급 3 2,502건; 안전관리 2권 2,238건(183·1,090·965); 제외 84권 9,279건(3,605·4,137·1,537 = 16.6%); 파일별 등급 3 비율 평균 8.5%·중앙값 0.0%·0건 57권; 장비 분야 19권 3,239건(등급 3 1,052) 중 `LM1903060329` 780건(74.1%), 제외 시 1,608건(272 = 16.9%).
- `semantic_summary.json` 은 말뭉치·분야·키워드 단위만 싣는다(`corpora.*.groups[]`, `keywords[].corpora.*.groups`). 교과서는 분야 = 교재라 `groups[]` 가 이미 교재별이지만 NCS 는 4개 분야뿐이다.
- **정본 재실행의 연쇄**(학습 `searchinmd-canonical-rerun-cascade`): `meta.run.generated_at` 이 2026-09-17 로 바뀌면 HWPX 출력 이름 `…_20260917_정본.hwpx`, 추적 대조 JSON `hwpx_results_refresh_20260917.json`(20260915 는 계보로 남음), 본문의 출처 문구("2026-09-15 정본 … 사전 v2"), `docs/semantic_recount_data.js`·분석 페이지 3종, 하니스 S2/S3, 문서(README·CLAUDE·data README·TODOS)·메모리가 함께 갱신된다. 수치·해시(manifest 4종)는 입력이 같으므로 변하지 않는다.
