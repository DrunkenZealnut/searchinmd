## 완료 내용

- 재검산 과정(정본 `semantic_keyword_recount_20260914.xlsx`, 2026-09-14)에 페이지 등급 결합 단계를 추가했다.

- 페이지 마커가 없는 출현은 그 줄의 문맥으로 판정하고(`unpaged-context`) 문맥이 비면 등급1을 배정한다(`unpaged-fallback`) — **연구책임자 승인 2026-09-13, 미배정을 두지 않는다.** 정본 코퍼스에서는 1건(마커 앞 제목 줄)뿐이다. (2026-09-09 판은 "등급 미확정으로 보존"이었고 813건이었다 — 그 813건은 요약본 4파일 742 + 중복 교재 70 + 제목 1 로, 코퍼스 정제로 소멸.)
- NCS와 교과서 대시보드를 공통 렌더러로 통합해 동일한 등급1~3 분석 흐름을 적용했다.
- 등급 비율과 차트의 분모를 페이지 수에서 의미 출현건수로 바꾸었다.
