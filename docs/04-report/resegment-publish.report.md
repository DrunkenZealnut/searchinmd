### Design

- **아키텍처 결정**
  - 정본 역할: `reseg_summary.json` (NCS 쪽 단위 수치)
  - 부정본 역할: `summary.json.ncs` / `ncs_pages.csv` (라벨 기준, 계보 확인용만)
  - 하니스 구조: D13a~p는 정본과 대시보드 일관성, D14·R17은 문서 참조 정확성 검증

- **하이브리드 배정 규칙**
  ```
  마커 N (줄 a) 다음 마커 M (줄 b), M ≥ N+2 이면:
    줄 a+1..b-1을 순서대로 보며:
      DP 쪽 p가 [N, M-1] 안에 들 때 p로 배정
      근거 없는 줄은 cur를 잇기 (구간 단조)
    앵커 보정: 구간 첫 본문 줄의 DP가 N 보다 앞서면 차이를 뺀다
  M = N+1 인 구간과 첫 마커 앞은 마커 그대로
  ```

| 결정 | 이유 |
|---|---|
| 마커 교재는 마커 그대로 + 하이브리드 구간만 보정 | 변환기가 쪽 마커를 찍어준 데이터 신뢰, DP 배정은 구간 보정에만 |
