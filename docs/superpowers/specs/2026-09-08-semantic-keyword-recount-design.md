## 목적

`data/ncs_keywords_in_markdown_results_20260402_재판정_20260414.xlsx`의 30개 키워드를 기준으로 `data/markdown/ncs`와 `data/markdown/school-text`의 모든 Markdown 원문을 다시 조사한다. 키워드와 의미가 같은 표기 변형·약어·영문명과, 그 키워드를 명백히 함의하는 구체 표현을 재현 가능한 규칙으로 정의한다. 원문에서 의미 표현의 출현 횟수·검출 파일 수·검출 페이지 수를 다시 계산하고, 정확 일치 기준선과 의미 확장분을 분리해 제시한다.

원본 워크북은 보존하며, 재검산 워크북과 사람이 읽을 수 있는 보고서를 별도 파일로 만든다.

## 입력 범위

- 기준 키워드: 원본 워크북의 30개 시트명
- NCS: `data/markdown/ncs/**/*.md` 89개. 이 중 84개에 페이지 마커가 있고 5개에는 없다.
- 교과서: `data/markdown/school-text/**/*.md` 9개. 9개 모두 페이지 마커가 있다.
- 페이지: Markdown 안의 `<!-- page: N -->` 마커가 있으면 해당 페이지를 사용한다. 마커가 없는 NCS 5개는 페이지 수에서 제외하지 않고 `페이지 미확정 파일 단위`로 별도 집계해 페이지 수와 섞지 않는다.
- `_meta.json`, `merged.json`, 이미지, 원본 XLSX 자체는 본문 스캔 대상에서 제외한다.
- Markdown의 제목·목록·표 본문은 검색 대상에 포함한다. 페이지 마커 주석과 이미지 URL 자체는 계수에서 제외한다.

## 계수 단위

각 문서의 본문을 Unicode NFC로 정규화하고, 영문은 대소문자를 구분하지 않으며, 등록된 복합어에 한해 띄어쓰기·가운뎃점·하이픈 변형을 허용한다. 원문 위치는 정규화 전 줄 번호로 역추적한다.

키워드별로 다음 단계를 분리한다.

1. `원문 정확 문자열`: 원래 키워드 문자열의 가공 전 출현 수
2. `동음이의 제외`: 정확 문자열이지만 다른 뜻인 출현 수. 예: 사고의 `부상`이 아니라 “산업으로 부상하다”의 `부상`
3. `유효 정확 표현`: 1에서 2를 뺀 값과 정규화된 표기 변형
4. `동등 표현 확장`: 약어·영문명·동의어처럼 같은 개념을 직접 지칭하는 표현을 추가
5. `구체 표현 확장`: 키워드 개념을 명백히 함의하는 하위 유형을 추가. 예를 들어 특정 보호구는 `보호구`를 함의한다.

최종 의미 확장 값은 3+4+5로 제시하되 동음이의 제외분과 각 확장 계층의 증가분을 별도 열로 남긴다. 단순 관련어는 어느 계층에도 넣지 않는다.

각 계층에는 다음 지표를 함께 산출한다.

1. `의미 출현 횟수`: 해당 키워드 표현군 안에서 겹치지 않게 매칭된 표현 수
2. `검출 파일 수`: 한 번 이상 매칭된 고유 Markdown 파일 수
3. `검출 페이지 수`: 페이지 마커 기준 고유 `(파일, 페이지)` 수
4. `페이지 미확정 파일 수`: 페이지 마커 없이 한 번 이상 매칭된 NCS 파일 수

같은 의미 표현이 한 문장에 여러 번 나오면 출현 횟수에는 각각 포함한다. 같은 키워드 표현군 안에서 긴 표현이 짧은 표현을 포함하면 긴 표현을 먼저 매칭하고 하나의 출현으로만 센다. 원본 워크북의 행은 문장·표·제목 검색 결과라 원문 출현 횟수와 단위가 다르므로 `원본 검색행 수`로만 병기하고 두 값 사이의 증감률은 계산하지 않는다.

## 포함 기준

표현은 아래 조건을 모두 만족해야 포함한다.

- 해당 키워드와 동일한 위험·사고·질환·법규·보호구·예방조치·관리 개념을 직접 가리키거나, 그 개념을 명백히 함의하는 구체 유형이다.
- NCS 또는 교과서 원문에 실제로 출현한다.
- 띄어쓰기·하이픈·괄호·영문 병기·약어·활용형 차이로 인한 표기 변형이거나, 안전보건 문맥에서 동일 개념을 명확히 지칭하는 구체 표현이다.
- 표현의 계층(`정확`, `동등`, `구체`)과 포함 근거를 설명할 수 있다.
- 문맥 의존 표현은 전체 출현 문맥을 추출해 포함 조건과 제외 조건을 규칙으로 고정할 수 있다.

## 제외 기준

- 단순히 관련이 있을 뿐 키워드 개념을 직접 지칭하거나 함의하지 않는 원인·결과·일반어
- 반도체 회로·공정·품질 문맥에서만 쓰이는 동음이의어
- 문맥 없이는 안전 의미를 확정할 수 있는 근거가 부족한 일반어
- 다른 포함 표현의 일부로만 나타나 별도 출현으로 세면 이중 계수가 되는 부분 문자열
- 원문에서 확인되지 않은 사전적 동의어 또는 외부 지식만으로 추정한 표현

애매한 표현은 억지로 포함하지 않고 `보류/제외 표현` 시트와 보고서에 문맥 근거를 남긴다.

## 후보 발견과 전수 판정

- 기존 프로젝트의 어휘 누락 조사 결과를 후보 씨앗으로 사용하되 자동 채택하지 않는다.
- 30개 키워드의 띄어쓰기·기호·영문·약어 변형과 안전보건 분야의 명시적 구체 유형을 후보로 만든다.
- 한 기존 키워드의 정확 문자열은 다른 기존 키워드의 확장 후보로 사용하지 않는다.
- 전체 98개 Markdown에서 기존 키워드와 같은 문장에 반복적으로 나타나는 미등록 명사·복합어를 추출해 추가 후보를 만든다.
- 모든 후보의 전체 출현 문맥을 기계적으로 추출한다. 문맥에 따라 의미가 갈리는 후보는 전건 확인 후 명시적 포함/제외 문맥 규칙을 만들며, 안정적인 규칙을 만들 수 없으면 보류한다.
- 원문에 한 번도 나타나지 않는 표현은 포함 사전에 넣지 않고 `미출현 후보`로 기록한다.

## 판정 및 중복 처리

- 각 키워드 표현군 안에서는 긴 문자열 우선, 동일 길이면 사전 등록 순서로 매칭한다.
- 30개 기존 키워드는 각각 독립된 분석 단위로 유지한다. 키워드 간 병합, 개념군 연결, 통합 집계는 하지 않는다.
- `MSDS`와 `물질안전보건자료`, `PSM`과 `공정안전관리`처럼 의미가 가까워도 기존 키워드끼리 서로의 포함 표현으로 등록하지 않는다.
- 새 후보 표현도 하나의 기존 키워드에만 귀속한다. 둘 이상의 기존 키워드에 동등하게 귀속될 여지가 있으면 보류한다.
- 30개 키워드의 출현 수를 합산한 총계는 만들지 않는다.
- `진동`, `먼지`, `분진`, `소음`, `접지`, `정전기`, `감지기`, `노출`, `취급`, `인체`처럼 문맥에 따라 의미가 갈리는 표현은 안전 문맥 조건을 별도로 둔다.
- 규칙이 인용하는 문맥 예시는 원문에서 추출한 짧은 근거 문장으로 기록한다. 원문 전체 본문은 결과 파일에 복제하지 않는다.

## 원본 워크북 처리

- 원본 30개 시트명은 키워드 목록으로 사용한다.
- `사망` 시트는 헤더가 없고 첫 행부터 데이터인 예외이므로, 단순히 첫 행을 제거하지 않고 헤더 이름 또는 데이터 행 구조로 판정한다.
- 원본 검색행 수는 빈 행과 실제 헤더만 제외해 계산한다.
- 31MB가 넘는 원본의 전체 행을 결과 파일에 복제하지 않는다. 대신 원본 경로·SHA-256·시트별 검색행 수를 `입력정보` 시트에 기록한다.

## 검증 조건

- 입력 파일 수와 키워드 30개가 보고서 및 엑셀 요약에 일치한다.
- 모든 매칭은 키워드·실제 매칭 표현·계층·출처 파일·줄 번호·페이지 마커로 역추적할 수 있다.
- `원문 정확 문자열`이 독립 단순 검색 결과와 일치하고, `원문 정확 문자열 - 동음이의 제외 = 유효 정확 표현` 관계가 성립한다.
- 같은 키워드 표현군 안의 매칭 구간은 겹치지 않는다.
- 어떤 기존 키워드 문자열도 다른 기존 키워드의 포함 표현으로 등록되지 않는다.
- 모든 신규 표현은 정확히 하나의 기존 키워드에만 귀속된다.
- 키워드 합계와 표현별·파일별·상세행 집계가 서로 일치한다.
- 페이지 마커가 없는 NCS 5개의 매칭은 페이지 수에 섞이지 않고 `페이지 미확정`으로 집계된다.
- 원본 워크북의 `사망` 무헤더 시트와 나머지 헤더 시트의 검색행 수가 올바르게 계산된다.
- XLSX가 정상적으로 열리고 모든 시트의 행·열 구조가 손상되지 않는다.
- 출력 파일을 두 번 독립 생성했을 때 표현 사전 해시, 상세 매칭 해시, 요약 값이 동일하다.

## 명시적 한계

- 의미 확장은 분석 규칙이지 자연어 의미의 완전한 판정기가 아니다. 문맥 규칙 밖의 애매한 표현은 보류한다.
- 원본 워크북의 검색행 수와 새 원문 출현 횟수는 계수 단위가 달라 직접적인 증감률로 해석할 수 없다.
- NCS 5개 파일은 페이지 마커가 없어 파일 단위까지만 확정할 수 있다.
- 30개 기존 키워드는 의미가 가까워도 통합하지 않는다. 따라서 키워드별 결과만 해석하고 전체 합계는 만들지 않는다.
